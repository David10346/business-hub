# Antigravity for Android — Service

**Service: Mobile AI Coding Environment setup — from $99 one-time.**

We set up Google Antigravity (Android port) on your Android phone or
tablet so you can build apps and websites with an AI agent, without a
computer.

## What you get
- Antigravity for Android installed (standard release only)
- Git, Python and Node.js runtimes installed (`pkg`)
- Connected to your GitHub repos
- Desktop mode configured for tablet / Samsung DeX
- 30-minute walkthrough of the agent workflow

## Requirements
- Android 7.0+ phone or tablet, ARM64
- Google account (for Gemini)
- GitHub account

## Setup (summary)
1. Download `antigravity.apk` from the original project's Releases page:
   https://github.com/werdio325-png/antigravity-android/releases
2. Install, grant Storage permission (All Files Access).
3. In the terminal: `pkg update && pkg install git python nodejs`
4. Open your repo, ask the agent to build.

Full step-by-step guide: see `SETUP.md` in this folder.
